# dsh-deep-diving-back v0.1.0

Date: 2026-09-25

首个版本: 把 DSH 0.1.6 及以前那个蓝色流光的 "深度求索中" 回合运行标志加回来.

## Highlights

- 运行中的回合在对话流最后一行重新显示蓝色流光的 "深度求索中", 运行满 15 秒后在右侧出现计时.
- 标志钉在流尾, 因此已并入当前请求的 steer 落在它之上, 仍在待处理的 steer 落在它之下, 与旧版语义一致.
- 系统开启减弱动态效果时, 该行退化为静态蓝色文字.

## Features

- 新增会话级对话节点种类 `deep-diving-status`, 只在回合打开时物化, 排序位在所有持久行之后.
- 注册 `conversation.chat.node` 的 keyed 渲染器, 复刻 0.1.6 `TurnStatus` 的外观, 计时阈值与字体轴 token.

## Upgrade Notes

1. 安装后重启宿主一次, 让 Client metadata 重新扫描.
2. 该行只在 DSH 0.1.7-alpha.1 及以后需要; 更低版本自带原版效果, 装上会出现两行.
